# 2026 춘천시 사전투표소 찾기

제9회 전국동시지방선거 춘천시 사전투표소 안내 및 더불어민주당 후보자 소개 페이지

## 미리보기

- **사전투표일**: 2026년 5월 29일(금) ~ 5월 30일(토)
- **투표 시간**: 오전 6시 ~ 오후 6시
- **지참물**: 신분증

## 주요 기능

- 춘천시 사전투표소 위치 검색 (읍·면·동·투표소·건물명)
- 사전투표소별 편의시설 정보 (승강기, 점자유도블럭, 장애인화장실 등)
- 약도 보기 (중앙선관위 e-doumi 연동)
- 더불어민주당 춘천시 후보자 안내 (시·도지사 / 기초단체장 / 광역의원 / 기초의원 / 비례)

## GitHub Pages 배포

이 저장소를 GitHub에 업로드 한 뒤, **Settings → Pages → Source: main / root** 로 설정하면
`https://{username}.github.io/chuncheon-prevote-2026/` 에서 바로 확인 가능합니다.
